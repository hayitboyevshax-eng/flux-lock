# Flux Lock
Depth-effect lock screen (Flutter).

Fonlar: `assets/wallpapers/wN.jpg` (to'liq) + `wN_fg.webp` (shaffof cutout, bir xil o'lcham).
O'z rasmingizni qo'shish: shu nomlash bilan joylang va `ClockSettings.wallpaperCount` ni oshiring.
Qayta yaratish: `python3 tool/gen_wallpapers.py` (numpy + pillow kerak).
Soatni uzoq bosing -> autentifikatsiya -> sozlamalar (fon tanlash ham shu yerda).
